# 💬 Real-Time Chat Application using Socket.IO

This is a responsive and fully functional **real-time chat app** developed using **Node.js**, **Express.js**, and **Socket.IO** for live communication. It allows users to join the chat room, send and receive messages instantly, view typing indicators, and get notified when users join or leave the chat.

---

## 📌 Project Overview

This project is a part of real-time web development using **WebSocket technology** through the Socket.IO library. It demonstrates how to create a chat system that allows multiple users to communicate in real-time.

> ✅ **Deliverable:** A Live Chat App with Frontend and Backend Integration

---

## ✨ Key Features

- 🌐 Real-time messaging using **Socket.IO**
- ✍️ \"User is typing...\" indicator visible to other users
- ✅ Notifications for user **joined** and **left** events
- 💡 Responsive UI that fits screen without scroll
- 📱 Mobile-friendly design
- 🌗 Dark mode toggle (with active user color adjustment)
- ⌚ Message timestamps
- 🚫 Scroll-free message input area
