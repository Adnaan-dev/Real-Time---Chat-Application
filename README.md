# 🔴 Real-Time Chat App  
## 💬 A Live Chat Application using HTML, CSS, JavaScript, Node.js, and Socket.IO

This is a fully functional and responsive **real-time chat app** built with **Socket.IO**, **Node.js**, **Express**, and simple frontend technologies like HTML, CSS, and JavaScript. It supports live chat, typing indicators, dark mode, and user join/leave notifications.

---

## 🔍 Features

- 🧑‍🤝‍🧑 **Join & Leave Notification** – Displays when a user joins or leaves the chat.
- 💬 **Real-Time Chat** – Messages are instantly sent and received.
- ✍️ **Typing Indicator** – See when someone is typing.
- 🌗 **Dark Mode Toggle** – Switch between light and dark themes.
- ⌛ **Message Timestamps** – Every message shows the time it was sent.
- 📱 **Responsive Design** – Works smoothly on all screen sizes.

## 🛠️ Key Technologies Used

- **HTML** – UI structure
- **CSS** – Styling and responsive layout
- **JavaScript** – Frontend logic
- **Node.js** – Backend runtime
- **Express.js** – Web server
- **Socket.IO** – Real-time bidirectional communication

---

## ⚙️ How It Works

1. When a user enters their name, they are connected to a chat room.
2. Users can send and receive messages in real-time.
3. While typing, other users see a “typing…” indicator.
4. When someone joins or leaves, a message notifies the room.

---

## 💡 Implementation Details

- `socket.emit()` is used to send events like messages, typing, join/leave.
- `socket.on()` receives and handles incoming events.
- User list is managed with socket IDs on the server.
- CSS Grid and Flexbox are used for layout and responsiveness.
- The dark mode is toggled with a class change and persists through the session.
